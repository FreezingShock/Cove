Use cases

Inlet for the way you work.Same grid. Same search.

Inlet is one full-screen grid and one search field for your apps and files. These pages show how it fits three kinds of work. Each one lists only features that Inlet has today.

Pick the page that fits.

Developers

Your tools, one keystroke away.

Open Xcode or Terminal by typing a few letters. Find project files through Spotlight. Build Inlet from source.

Read the developer page Designers

Real icons and fixed springs.

Each app shows its own icon. Motion uses seven springs with values you can check, and the accessibility settings work with nothing to set up.

Read the designer page Students

Every class app in one place.

Sort apps into School, Create and Build. Keep a folder for each class, and find an essay or a PDF by its name.

Already use Spotlight?

Inlet doesn't replace it. Inlet uses Spotlight's file index and adds a grid you can arrange. The comparison page shows where each one fits.
