Install guide

Install Inlet, one step at a time.

Inlet is not notarized by Apple yet, so macOS stops the first launch. This guide shows what you will see at each step, so you know what to click. It takes about two minutes.

Step 1 of 4

Drag Inlet into Applications

  1. Click Download for Mac. Your browser saves Inlet.dmg to Downloads.
  2. Double-click Inlet.dmg to open it. A window appears.
  3. Drag the Inlet icon onto the Applications folder in the same window.
  4. When the copy finishes, eject the disk image in Finder.

Want to check the download first? Compare its checksum with SHA256SUMS.txt on the release page. Run shasum -a 256 ~/Downloads/Inlet.dmg in Terminal.

Step 2 of 4

Open Inlet. macOS blocks it once.

  1. Open Applications and double-click Inlet.
  2. macOS says it cannot check the app. Click Done.

This is the expected first-launch warning, not damage to the app. Right-click and Open does not get past it on recent macOS, so go on to step 3.

Step 3 of 4

Allow Inlet in Privacy & Security

  1. Open System Settings from the Apple menu, then choose Privacy & Security in the sidebar.
  2. Scroll to the Security section. Next to “Inlet was blocked”, click Open Anyway.
  3. Type your Mac password, or use Touch ID, when macOS asks.
  4. If macOS asks once more, click Open. Inlet starts.

The Open Anyway button stays for a short time after your first try. If it has gone, open Inlet once more, and it comes back.

Prefer Terminal?

This removes the download flag, so macOS stops blocking the app. Use it instead of step 3 if the button does not show up.

xattr -dr com.apple.quarantine /Applications/Inlet.app

Then open Inlet from Applications as usual.

Step 4 of 4

Choose what Inlet can see

Inlet asks for very little. It works without either permission below, and you can change both later.

  • Files and Folders (optional). Lets Inlet find documents in Desktop, Documents and Downloads through Spotlight. Inlet reads only the search results. Set it in the welcome window on first launch, or later under Privacy & Security, Files and Folders.
  • Open at login (optional). Starts Inlet when you sign in. Turn it on in Inlet’s Settings, General, under Open at login.

Inlet does not ask for Accessibility or Screen Recording access in this version, so you should never see those prompts.

Also in Settings

Start Inlet at login

Open Inlet, choose Settings, then General. Switch on Open at login if you want Inlet ready as soon as you sign in. You can also see the switch under Login Items in System Settings.

Inlet opens from anywhere with Option Space by default. Change the shortcut in Settings, Keyboard.

After install

Updates arrive on their own

Inlet checks GitHub about once a day for a newer release. When it finds one, it offers the update through Sparkle, the standard Mac updater. The check asks only for release information. It never sends your files, your searches or your app list.

To turn the automatic check off, open Settings, then About, and switch off Check for updates automatically. You can still check by hand from the Inlet menu, with Check for Updates….

You go through steps 2 and 3 once, on the first install. Updates are meant to install without them. If macOS blocks an update, open an issue on GitHub so it can be fixed.

If something looks different.

Most first-launch problems come down to one of these. Open the one that matches what you see.

Inlet is “damaged” and can’t be opened

The app is not damaged. macOS shows this message for apps that are not notarized and still carry the download flag. Use the Terminal command in step 3:

xattr -dr com.apple.quarantine /Applications/Inlet.app

Then open Inlet again. Only the Terminal route gets past this message, so do not move the app to the Trash.

The Open Anyway button is gone

macOS keeps the button for a short time after the first attempt. Open Inlet once more from Applications, then go back to Privacy & Security, and it returns. If it still does not show, use the Terminal command.

Option Space does nothing

Another app may already use Option Space. Open Inlet’s Settings, then Keyboard, and record a different shortcut.

I don’t see Inlet in the Security section

Open Inlet from Applications once. The attempt puts it in the list. If you have already clicked Done, that is enough. Then check Privacy & Security again. If it still is not there, use the Terminal command.
