For developers

Your dev tools, one keystroke away.Project files included.

Inlet opens any app from a full-screen grid, or from a small panel at the Dock. Type a few letters, press Return, and the app opens. File results come from Spotlight, so Inlet finds what macOS has indexed.

Open a tool by typing part of its name.

The grid filters as you type and highlights the top match. Press Return to open it. That works for Xcode, Terminal, a database client, or anything else in your Applications folder.

  • Option Space opens the full grid by default
  • Control Option Space opens the quick panel
  • Both shortcuts can be changed in Settings, Keyboard

Find a file without its folder path.

Matching files appear under the apps, and Inlet keeps no index of its own. Spotlight is the source, so the results match what Spotlight would return.

Return opens it

When a file is the top match, Return opens it in its default app.

Command Return reveals it

Show the file in Finder when you need its folder, or the files around it.

Missing files have a cause

Spotlight only finds what it has indexed. If a project folder is excluded in System Settings, Siri & Spotlight, its files won't appear in Inlet either.

Keep the Build category together.

Inlet sorts apps by the category each one declares to macOS. Developer tools land in Build, so the Build filter shows your developer tools together. Apps you never open can go out of the grid.

  • Developer tools are sorted into Build
  • Hide third-party apps in Edit mode
  • Hidden apps come back from the Hidden list, in their old place

Apple's apps can't be hidden. The Hidden list only holds third-party apps. Use it to take out the installers, updaters and utilities you never open.

Build Inlet from source.

The source is on GitHub. Clone the repository, open Inlet.xcodeproj in Xcode, and build the app yourself. The download page has the build steps and the first-launch warning.

View the source Build steps

What Inlet leaves to your editor.

Inlet opens apps and files. It doesn't run scripts, open a project in your editor, or manage terminal windows. Your editor, your terminal and your own scripts handle those, and Inlet stays out of the way.

Nothing leaves your Mac except one update check.

No accounts

No sign-in, no profile, no sync between machines.

No analytics

Inlet doesn't track what you open or search for.

Crash reports stay put

Reporting is off unless you turn it on. Reports stay on your Mac until you share one.

One daily check

Inlet checks GitHub for updates about once a day. You can turn that off.
