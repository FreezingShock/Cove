What changes in each version.

Inlet is still in development, so there is no public release to list yet. Each version gets its own entry here when it ships, newest first. Until then, this page shows the plan.

  • Version plan

Version plan

From a plain grid to a daily driver.

  1. 0.1Skeleton

    A working grid of your apps

    An Xcode project that scans your app folders and shows every installed app with its real icon. Click an icon to open the app.

  2. 0.2Overlay

    Full-screen, instant, and on a shortcut

    A full-screen glass overlay that appears at once and closes on Escape. A global hotkey opens it from any app.

  3. 0.3Search

    Find an app or a file by typing

    Filter apps as you type, with a highlighted top match, Spotlight file results, and keyboard navigation.

  4. 0.4Dock panel

    A quick panel from the Dock

    Click the Dock icon to open a compact panel with recent apps and recent files.

  5. 0.5Polish

    The finished look

    A full design pass, the final app icon, the animations, and the Settings window.

  6. 1.0Daily driver

    Ready for everyday use

    Fixes from a week of daily use with no crashes. Edit mode, folders, pages and hidden apps are part of this release. Each release lists what it leaves out, so the notes never promise more than the build does.

How notes are written

Written from the changes, checked before release.

From merged changes

Each entry comes from the titles of the changes that went into the release. Titles are written to be read by people, and any title that reads badly is fixed before the release goes out.

Known limits

Every release states what is not in it yet. Features on the plan but not shipped are listed as not included, not as done.

Want the full history? Every change is in the commit history on GitHub. Releases are on the releases page.
