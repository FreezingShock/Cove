Release notes and the plan.

Inlet is still in development, so no release is out yet. Each version gets an entry here when it ships, newest first. Until then, the plan is below.

Roadmap to 1.0

Four milestones are built. Two remain before 1.0.

Each status is checked against the code on the integration branch, as of 17 November 2026. Nothing has shipped yet, so every entry below is work in the code, not a release.

  • Built
  • In progress
  • Waiting on a key
  • Not started
  1. 0.1SkeletonBuilt

    A working grid of your apps

    Scans your app folders and shows every installed app with its real icon. Click an icon to open the app.

  2. 0.2OverlayBuilt

    Full-screen, instant, and on a shortcut

    A full-screen glass overlay that appears at once. A global hotkey opens it from any app, and Escape closes it.

    HotkeyEsc
  3. 0.3SearchBuilt

    Find an app or a file by typing

    Apps filter as you type. Spotlight adds file results, and the top match is highlighted.
