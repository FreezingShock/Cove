Get Inlet

Get Inlet running on your Mac in a minute.

Download the disk image, drag Inlet into Applications, and open it. Inlet needs macOS 26 or later. Some builds are not notarized yet, so the first launch may need one extra step.

Download Inlet All releases on GitHub
macOS 26 or later No account needed

No release is out yet? The download button points to the newest published release on GitHub. If it shows a GitHub 404 page, no release has been published yet. Until one is, you can build Inlet from source.

Three steps.

  1. Download the disk image

    Click Download Inlet. Your browser saves Inlet.dmg to Downloads.

    To check the file, compare its checksum with SHA256SUMS.txt on the same release page:

    shasum -a 256 ~/Downloads/Inlet.dmg

  2. Drag Inlet into Applications

    Open Inlet.dmg, then drag the Inlet icon onto the Applications folder next to it. Eject the disk image when the copy finishes.

  3. Open Inlet

    Open Inlet from the Applications folder. If macOS opens it without a warning, you are done. If macOS says it cannot verify the app, go to First launch.

Get past the first-launch warning.

Notarized releases open with no warning. A build that is not notarized is blocked the first time, so macOS asks you to allow it once. Use either method below.

  1. In Finder

    1. Open Inlet. macOS says it cannot verify the app. Click Done.
    2. Open System Settings, then Privacy & Security.
    3. Scroll to the Security section and click Open Anyway next to Inlet. Confirm with your password.

    macOS keeps the Open Anyway button for a short time after the first attempt. If it is gone, open Inlet again and it will return.

  2. In Terminal

    Remove the download flag from the app, then open Inlet as usual:

    xattr -dr com.apple.quarantine /Applications/Inlet.app

  3. Choose what Inlet starts with

    Open at login is a setting, not a requirement. Turn it on in Settings, General if you want Inlet to start when you log in. Inlet doesn't ask for Accessibility or Screen Recording access in version 1.

    Right-click does not bypass this check on recent macOS releases, so use one of the two methods above.

Build it yourself with Xcode.

You need macOS 26 and Xcode 26 or later. Xcode is free from the Mac App Store. You do not need a paid Apple Developer account.

  1. Get the code

    Clone the repository, or choose Code, Download ZIP on GitHub and unzip it.

    git clone https://github.com/FreezingShock/Cove.git

  2. Open and run the project

    Double-click Inlet.xcodeproj. Make sure the scheme reads Inlet and the destination reads My Mac, then press Command R.

    If Xcode asks for a development team, open the Inlet target, go to Signing & Capabilities, and choose Sign to Run Locally.

  3. Keep it

    Choose Product, Show Build Folder in Finder, open Products/Debug, and copy Inlet.app to Applications. It then opens like any other app.

Updates are checked once a day.

Inlet checks GitHub about once a day for a newer release. The check asks only for release information. It never sends your files, your searches or your app list. To update by hand instead, turn the automatic check off in Settings.

Remove Inlet and its data.

  1. Turn off Open at Login

    In Inlet, open Settings, General and switch off Open at login. Do this first, so macOS does not try to start a missing app.

  2. Move the app to the Trash

    Drag Inlet.app from Applications to the Trash, then empty the Trash.

  3. Delete the data folder (optional)

    Inlet keeps its settings, recent apps and files, and any diagnostic reports in one folder. Delete it to remove them completely:

    ~/Library/Application Support/Inlet
