Opening Inlet

How do I open Inlet?

Click Inlet's icon in the Dock to open the quick panel. It shows your recent apps and files, plus a Show All Apps button. Press ⌥ Space to open the full grid of apps from anywhere. If you turn on the menu bar icon in Settings, you can open Inlet from there too.

What does Inlet replace?

Launchpad. Apple removed it in macOS 26 Tahoe, so Inlet brings back a full-screen grid of your apps, with search for apps and files on top.

Which Mac does Inlet need?

Inlet needs macOS 26 or later.

Do I need an internet connection?

No. Inlet works offline. Its only outside connection is the update check, which you can turn off in Settings.

macOS says it can't verify Inlet, so it won't open

Early builds of Inlet aren't signed with an Apple Developer ID yet, so macOS may block the first launch. Only do this for a copy you downloaded from Inlet's official GitHub releases page. Then follow these steps on macOS 15 and later:

  1. Open Inlet from your Applications folder. When macOS shows the warning, click Done.
  2. Open System Settings, then Privacy & Security.
  3. Scroll down to the Security section. You'll see a message that Inlet was blocked. Click Open Anyway and enter your password if asked.
  4. Click Open in the confirmation dialog. Inlet will open, and macOS won't ask again.

Hotkey problems

⌥ Space types a strange space in other apps

Inlet's default grid shortcut is ⌥ Space. macOS normally uses that combination to type a non-breaking space, so while Inlet is running, that key goes to Inlet first. If you'd rather keep the character, change the grid shortcut in Settings, Keyboard. The quick panel's default, ⌃ ⌥ Space, is separate and can be changed too.

The shortcut doesn't open Inlet

Another app or a macOS shortcut may already use the same keys. Inlet shows a message when a shortcut is already taken. Pick a different combination in Settings, Keyboard. Inlet doesn't use ⌘ Space, because that opens Spotlight.

Some apps block global shortcuts, and password fields do too. macOS does this on purpose to protect what you type. Click outside the field or switch to another app, then try again.

Arrow keys or Tab don't move through results the way I expect

Full Keyboard Access changes how Tab and the arrow keys move focus in macOS apps. Check it in System Settings, Accessibility, Keyboard. Turn it off and try again. If the problem stays, report it with your macOS version.

Permissions

Does Inlet ask for Accessibility or Screen Recording access?

No, not in version 1. You won't see those prompts.

How do I turn off launch at login?

Open System Settings, General, Login Items, and switch off Inlet.

Why doesn't a file show up in search?

Inlet's file results come from Spotlight, which only finds what it has indexed. If a folder is excluded from Spotlight in System Settings, Siri & Spotlight, files in it won't appear in Inlet either. Inlet doesn't keep its own index.

Erasing data

How do I clear my recent apps?

Open Settings, Privacy and choose Erase Launch History. This clears the recent apps Inlet shows in its quick panel. Recent files come from Spotlight, so Inlet can't clear those. Clear them from Spotlight's own settings if you need to.

How do I erase saved crash reports?

Open Settings, Privacy and use the Erase button. Inlet keeps crash reports only if you turned on crash reporting, and it keeps up to 20 of them on your Mac. Nothing is sent anywhere unless you choose to share a report.

How do I remove Inlet completely?

Quit Inlet. Move it from your Applications folder to the Trash, then empty the Trash. To delete your settings, launch history, and saved crash reports too, open Finder, choose Go, Go to Folder, and enter ~/Library/Application Support/Inlet. Move that folder to the Trash as well.

Report a bug

Open a new issue on Inlet's GitHub issues page. A good report includes:

  • Your macOS version, from the Apple menu, About This Mac.
  • Your Inlet version, from About Inlet in the Inlet menu.
  • What you did, step by step, and what happened instead.
  • A screenshot or screen recording, if it helps.

GitHub issues are public, so remove personal details before you post. That includes file names and folder paths you don't want shared. If you turned on crash reporting, Send Feedback in the Help menu lets you preview a report before you share it.

If Inlet crashed and you want to look at macOS's own crash log, open the Console app and choose Crash Reports in the sidebar. Those logs include file paths and your user name, so check them before you share one.
