Opening Cove

How do I open Cove?

Click Cove's icon in the Dock to open the quick panel. It shows your recent apps and files, plus a Show All Apps button. Press ⌥ Space to open the full grid of apps from anywhere. If you turned on the menu bar icon in Settings, you can also open Cove from there.

What does Cove replace?

Launchpad. Apple removed it in macOS 26 Tahoe, so Cove brings back a full-screen grid of your apps, with search for apps and files on top.

Which Mac does Cove need?

Cove needs macOS 26 or later. It is built for Apple silicon and Intel Macs running that version or newer.

Do I need an internet connection?

No. Cove works offline. Its only outside connection is the update check, which you can turn off in Settings.

macOS says it can't verify Cove, so it won't open

Early builds of Cove aren't signed with an Apple Developer ID yet, so macOS may block the first launch. Only do this for a copy you downloaded from Cove's official GitHub releases page. Then follow these steps (macOS 15 and later):

  1. Open Cove from your Applications folder. When macOS shows the warning, click Done.
  2. Open System Settings, then Privacy & Security.
  3. Scroll down to the Security section. You'll see a message that Cove was blocked. Click Open Anyway and enter your password if asked.
  4. Click Open in the confirmation dialog. Cove will open, and macOS won't ask again.

Hotkey problems

⌥ Space types a strange space in other apps

Cove's default grid shortcut is ⌥ Space. macOS normally uses that combination to type a non-breaking space, so while Cove is running, that key goes to Cove first. If you'd rather keep the character, change the grid shortcut in Settings, Keyboard. The quick panel's default, ⌃ ⌥ Space, is separate and can be changed too.

The shortcut doesn't open Cove

Another app or a macOS shortcut may already use the same keys. Cove shows a message when a shortcut conflicts with one that's already taken. Pick a different combination in Settings, Keyboard. Cove doesn't use ⌘ Space, because that opens Spotlight.

Some apps block global shortcuts, and password fields do too. macOS does this on purpose to protect typing. Click outside the field or switch to another app, then try again.

Arrow keys or Tab don't move through results the way I expect

Full Keyboard Access changes how Tab and the arrow keys move focus in macOS apps. Check it in System Settings, Accessibility, Keyboard. Turn it off, try again, and if the problem stays, report it with your macOS version.

Permissions

Does Cove ask for Accessibility or Screen Recording access?

No, not in version 1. You won't see those prompts. Cove only asks macOS for what it needs to work, and it leaves the rest alone.

How do I turn off launch at login?

Open System Settings, General, Login Items and switch off Cove. You can also turn it off in Cove's own Settings.

Why doesn't a file show up in search?

Cove's file results come from Spotlight, which only finds what it has indexed. If a folder is excluded from Spotlight in System Settings, Siri & Spotlight, files in it won't appear in Cove either. Cove doesn't keep its own index.

Erasing data

How do I clear my recent apps and files?

Open Settings, Privacy and choose Erase Launch History. This clears the recent apps Cove shows in its quick panel. Recent files come from Spotlight, so Cove can't clear those. Clear them from Spotlight's own settings if you need to.

How do I remove Cove completely?

Quit Cove. Move it from your Applications folder to the Trash, then empty the Trash. To delete your settings and launch history too, open your Library's Application Support folder and remove the folder for Cove. Look for a folder named Cove, or search that folder for it if it isn't where you expect.

Report a bug

Open a new issue on Cove's GitHub issues page. A good report includes:

  • Your macOS version, from the Apple menu, About This Mac.
  • Your Cove version, from Settings, About.
  • What you did, step by step, and what happened instead.
  • A screenshot or screen recording, if it helps.

Remove personal details before you post, such as file names or folder paths you don't want public. If Cove crashed, you can find the crash report in the Console app, under Crash Reports. Crash reports include file paths and your user name, so check them before you share one. Crash reporting is off by default, so nothing is sent unless you choose to send it.
